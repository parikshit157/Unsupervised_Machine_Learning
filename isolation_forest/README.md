# Thyroid Disease Anomaly Detection using Isolation Forest

## Overview
This project applies the **Isolation Forest** algorithm to detect anomalies in a thyroid dataset. The model identifies unusual patient records using an unsupervised machine learning approach.

## Dataset
**Thyroid Dataset** 

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Seaborn  

## Model
Isolation Forest is used for outlier detection 

## Results
The model detects abnormal patterns in thyroid patient records and helps identify potential outliers in the dataset.
