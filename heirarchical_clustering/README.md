# Hierarchical Clustering

## Overview

This project performs data clustering using the Hierarchical Clustering algorithm. The objective is to group similar data points into clusters based on their feature similarity. A dendrogram is used to analyze the hierarchical relationships between data points and to determine the optimal number of clusters.

## Workflow

1. Load the dataset.
2. Scale the features using StandardScaler.
3. Generate a dendrogram to identify the optimal number of clusters.
4. Apply Agglomerative Hierarchical Clustering.
5. Visualize and analyze the resulting clusters.

## Technologies Used

* Python
* Scikit-learn
* Seaborn

## Results

The dataset was successfully divided into meaningful clusters using Hierarchical Clustering. The dendrogram helped determine an appropriate number of clusters, allowing for effective grouping and analysis of similar data points.
